# Lost & Found

## Introduction

Lost & Found is a Flutter mobile application for Android and iOS that helps users report, search, and retrieve lost or found items. The project aims to streamline the process of reuniting people with their belongings using a simple and effective interface. It is suitable for institutions, public places, or communities looking to facilitate item recovery.

## Features

- User authentication and registration
- Post lost or found item reports with detailed descriptions and images
- Search and filter items by category, location, or status
- Contact system between item posters and seekers
- Administrative dashboard for managing users and reports
- Modern, responsive user interface built with Flutter widgets

## Requirements

To run Lost & Found on a mobile device, ensure the following minimum platform versions:

- Android: Android 6.0, API level 23, or higher
- iOS: iOS 12.0 or higher

## Usage

Getting started with Lost & Found on Flutter is straightforward:

1. Clone the repository:
   ```bash
   git clone https://github.com/mehroj-r/lost-n-found.git
   cd lost-n-found
   ```
2. Install Flutter dependencies:
   ```bash
   flutter pub get
   ```
3. Connect an Android device or iOS device, or start an emulator or simulator.
4. Run the application:
   ```bash
   flutter run
   ```
5. The app will launch on the selected device or emulator.

## Installation

Follow these steps for installation on your development machine:

1. Install the Flutter SDK and add it to your system PATH.
2. Install Android Studio and the Android SDK, and optionally Xcode for iOS development.
3. Clone the repository and fetch dependencies:
   ```bash
   git clone https://github.com/mehroj-r/lost-n-found.git
   cd lost-n-found
   flutter pub get
   ```
4. Set up at least one Android emulator or iOS simulator, or connect a physical device.
5. Run the app in debug mode:
   ```bash
   flutter run
   ```
6. For a release build, use:
   ```bash
   flutter build apk    # Android
   flutter build ios    # iOS
   ```
